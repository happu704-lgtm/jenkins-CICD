# jenkins-CICD

### End-to-End CI/CD Pipeline for Spring PetClinic

**Technologies:** AWS EC2, Jenkins, Maven, SonarQube, Nexus Repository Manager, Apache Tomcat, Git, GitHub, Java, Spring Framework.

- Designed and implemented an end-to-end CI/CD pipeline using Jenkins to automate the build, testing, code quality analysis, artifact management, and deployment of the Spring PetClinic application.
- Integrated Maven for application compilation, testing, and WAR packaging, and SonarQube for automated static code analysis and quality gate evaluation.
- Configured Nexus Repository Manager to store and manage versioned WAR artifacts for centralized artifact management.
- Automated application deployment to Apache Tomcat hosted on AWS EC2 instances using Jenkins pipeline stages.
- Integrated GitHub for source code management and automated pipeline triggering through GitHub push events.
- Successfully executed the complete CI/CD workflow, from source code checkout to application deployment.
